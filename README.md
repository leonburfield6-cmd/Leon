# Nymeliaa Crochet 🧶

Application web de crochet pour [@nymeliaa_c](https://www.tiktok.com/@nymeliaa_c). Elle s'installe sur le téléphone et marche hors ligne.

## Fonctionnalités
- **Projets** : nom, crochet, laine, rangs prévus, icône, couleur, progression, statut terminé
- **Compteur** : compteur de rangs géant, compteur de mailles, chronomètre, notes par projet (vibration, touches espace / ↑ / ↓)
- **Points** : 15 points avec symbole, abréviations FR/EN et explication, recherche
- **Calculs** : répartition des augmentations et diminutions, générateur de boule amigurumi, échantillon → dimensions, pelotes nécessaires, tableau crochet ↔ laine
- Thème clair / sombre, données gardées dans le navigateur (localStorage)

## Lancer
Ouvre `index.html`, ou sers le dossier : `python3 -m http.server`, puis va sur http://localhost:8000.
Pour l'installer sur un téléphone, publie le dossier (GitHub Pages par ex.), ouvre le lien puis « Ajouter à l'écran d'accueil ».
